What gets deleted, and how

Junk and cache files are removed permanently, because the apps that made them will make them again. Your own files — duplicates and large files — always go to the Recycle Bin instead, so you can get them back.

Design notes

The capacity readout

Avast and CleanMyMac both open on a circular gauge, so this goes the other way: one honest linear bar of the real drive, with the reclaimable slice sitting against the free segment because that is where it is about to go. It is the app's existing 3px row meter at hero scale, fed by DriveInfo.

No invented percentages

The scanners report a running file count, not a fraction, so scanning shows an indeterminate bar and the real count. The dashboard is the one place a determinate stepper is truthful — "2 of 4 tools finished" is a real fraction.

One accent, one exception

Teal stays the only accent, spent on reclaimable space and the primary action. Red is added for one job: destructive confirmation. Today Scan and Delete are the same teal button, so one colour means both "look" and "cannot be undone".

Type

Space Grotesk stays for labels and titles. Open Sans — the project template's default — is replaced by IBM Plex Sans, drawn for engineering documentation and a natural partner to JetBrains Mono, which continues to carry every figure and path.
